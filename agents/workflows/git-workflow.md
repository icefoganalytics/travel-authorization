# Git Workflow

Use the shared [Git Rebase Workflow](https://github.com/klondikemarlen/marlens-skills-rules-and-tools/blob/main/docs/workflows/git-rebase-workflow.md) for rewording older commits, rebasing, autosquashing, and related history rewrites. Follow its safety gates; do not use the obsolete detach/amend/rebase sequence formerly documented here.

TravelAuth-specific rule: never force-push to `main`.

For commit message guidance, see [COMMITTING.md](../../COMMITTING.md). This local entrypoint remains for existing callers; use the shared workflow as the authoritative procedure.
