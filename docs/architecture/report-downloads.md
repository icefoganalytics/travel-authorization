# Travel Desk Report Downloads

How Travel Desk request-list selections become server-generated PDF and CSV downloads.

## Download Contract

Travel Desk PDF and CSV reports are generated by the API, not the browser. The browser submits an authenticated form to a download URL with the usual `where`, `filters`, and `order` query options; row selection uses `where[id]`. The [download controller](/api/src/controllers/downloads/travel-desk-travel-requests-controller.ts) applies the same policy scope as the request list and exports all matching authorized requests without list pagination. Export services throw when no visible requests match. The controller's `create()` action handles these errors and generation failures with a `422` JSON response, before setting download headers.

Both formats use `Export, Travel Desk Requests, YYYY-MM-DD` filenames with the appropriate `.csv` or `.pdf` extension.

The [shared query decoder](/api/src/utils/enhanced-qs-decoder.ts) supports query arrays of up to 1,000 entries, with at most 1,500 query parameters overall. Oversized queries are rejected instead of silently changing the selection.

## Data Loading and Generation

Controllers pass policy-scoped models and query options to the export services. The download namespace's unpaginated [IndexService](/api/src/services/downloads/travel-desk-travel-requests/index-service.ts) owns the required associations and serialization; exports do not run the list's total-count query.

The [template client](/api/src/templates/template-client.ts) uses the configured template root and WRAP's `{{ ... }}` interpolation. Its `htmlToPdf` method delegates to the reusable [PDF client](/api/src/lib/pdf-client.ts) through `pdfClient.htmlToPdf(htmlDocument, options)`. `PdfClient` owns Puppeteer configuration, rendering, and browser cleanup without Travel Desk dependencies. The [PDF service](/api/src/services/downloads/travel-desk-travel-requests/create-pdf-service.ts) owns report layout and PDF options, escaped local templates, and the embedded logo. The [CSV service](/api/src/services/downloads/travel-desk-travel-requests/create-csv-service.ts) uses `fast-csv`, a UTF-8 byte-order mark, and spreadsheet-formula neutralization.

## Runtime Packaging

Both [development](/api/development.Dockerfile) and [production](/Dockerfile) images provide system Chromium through `PUPPETEER_EXECUTABLE_PATH` and disable Puppeteer's bundled browser download. The production build copies `src/templates` into `dist/templates`. Keep Chromium and Puppeteer compatible, and exercise an actual generated PDF when changing either dependency or image.
